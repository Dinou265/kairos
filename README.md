# Kairos

**The right hackathon, at the right time.**

Kairos is a curated feed where tech students discover hackathons, competitions, and innovation events before registration closes.

## Add an event

1. Open `events.json`.
2. Copy an existing event object.
3. Replace the fields with the real event details.
4. Set `status` to `"live"` only after checking the registration link and deadline.
5. Commit and push—the site updates automatically.

## Deploy

Enable GitHub Pages from the `main` branch, root directory. The site will be available at:

`https://dinou265.github.io/kairos/`
